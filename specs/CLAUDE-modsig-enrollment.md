# CLAUDE-modsig-enrollment.md — Module Signing & IMA Enrollment Tooling

## What this is

Enrollment and signing tooling for deploying PyPKI-issued `code_signing` certificates
to Linux hosts that enforce kernel module signatures (`module.sig_enforce=1`) and/or
IMA appraisal (`ima_appraise=enforce`). Implements both trust models established by
the `MODSIG_TRUST_MODEL.md` experiment.

## Trust-model summary (from MODSIG_TRUST_FINDINGS.md)

| Mode | Mechanism | Blast radius | Op cost |
|------|-----------|--------------|---------|
| `leaf` (default) | Stock PKCS#7 (`CMS_NOCERTS`); leaf cert enrolled per-host | Narrow — only enrolled leaf | High — re-enroll on rotation |
| `ca` | PKCS#7 with embedded cert; CA root enrolled once per host | Broad — any leaf the CA issues | Low — one-time per machine |

IMA is always per-leaf regardless of module signing mode.

## Wire surface

No new HTTP endpoints. This is a pure client-side tooling layer:
- `modsig_enroll.py` — Python module (importable)
- `pypki_admin modsig-sign`, `modsig-enroll`, `ima-sign`, `ima-enroll` subcommands
- `harness/enroll_modsig.sh` — shell enrollment script
- `harness/modsig_roundtrip.sh` updated — adds `--trust-mode ca|leaf`

## Implementation

### `modsig_enroll.py`

**`ModsigSigner`**: signs `.ko` files via `openssl cms -sign`. Key flag:
- `embed_cert=False` (per-leaf): adds `-nocerts` → stock sign-file behavior
- `embed_cert=True` (per-CA): omits `-nocerts` → cert embedded, kernel can chain to root

Format assembled: `[module_body][pkcs7_der][struct module_signature (12 B)][MODULE_SIG_STRING (28 B)]`

`struct module_signature` fields for PKCS#7 mode:
```
algo=0, hash=0, id_type=2 (PKEY_ID_PKCS7), signer_len=0, key_id_len=0, pad[3]=0, sig_len=<be32>
```

**`ModsigEnroller`**: takes `ca_cert_der` + optional `leaf_cert_der`; `recipe(mode)` returns
`EnrollmentRecipe` with volatile keyctl commands, persistent MOK / dracut artifacts.

**`IMAEnroller`**: takes `leaf_cert_der`; `recipe()` returns `EnrollmentRecipe` for `.ima` keyring.

### Dracut hook format

Generated shell script (`pre-udev/99-pypki-modsig-{mode}.sh`):
```bash
#!/bin/sh
# pypki module-signing enrollment hook — generated by pypki_admin modsig-enroll
echo "<BASE64_CERT>" | base64 -d | keyctl padd asymmetric 'pypki-modsig' \
    %:.secondary_trusted_keys >/dev/null 2>&1
```

Dracut conf fragment (`/etc/dracut.conf.d/pypki-modsig.conf`) installs the hook
script and the cert DER into the initramfs so they survive ramdisk rebuilds.

### `harness/enroll_modsig.sh`

Environment:
- `TRUST_MODE` — `ca` | `leaf` (default: `leaf`)
- `ENROLL_METHOD` — `keyctl` | `mok` | `dracut` (default: `keyctl`)
- `HARNESS_OUT` — cert directory from `issue_cert.sh`

Modes:
- `keyctl` — volatile runtime enrollment via `keyctl padd`
- `mok` — persistent enrollment via `mokutil --import` (requires reboot + MokManager)
- `dracut` — generate and install dracut hook for persistent enrollment across reboots

### `harness/modsig_roundtrip.sh` additions

New flag `--trust-mode ca|leaf` (default: `leaf`):
- `leaf`: existing B1–B4 gates (unchanged)
- `ca`: adds gate B5 — signs `hello.ko` with embedded cert (openssl cms, no `-nocerts`),
  ensures leaf absent from all keyrings, runs `insmod` — expects exit=0
